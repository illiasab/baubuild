BAU BUILD API

Version 1. Base URL https://api.vesperconnect.org. Machine-readable spec: /v1/openapi.json.

Send Authorization: Bearer <access_token> except on the public routes below. Errors look like {"error":{"code":"...","message":"..."}}.

1. Auth

Microsoft authorization-code + PKCE. The server checks the Microsoft token, then the email domain: @stu.bau.edu is a student, @bau.edu is staff, anything else is 403 domain_not_allowed. Windows and Linux use a loopback redirect (http://127.0.0.1:{port}) registered in Entra. iOS, macOS, and Android use their custom-scheme redirects. Access tokens expire in one hour. Refresh rotates the refresh token; presenting a used refresh token revokes that session.

MethodPathAuthNotes
POST/v1/auth/microsoft/exchangePublicBody: { code, code_verifier, redirect_uri, device: { platform, app_version } }. platform is ios | macos | android | windows | linux. Returns { access_token, refresh_token, expires_in, user, entitlement }. 503 microsoft_not_configured until MICROSOFT_CLIENT_ID is set.
POST/v1/auth/refreshPublicBody: { refresh_token }. Returns a new pair. Reuse returns 401 refresh_reused and signs that device out.
POST/v1/auth/logoutBearerRevokes the current session. 204.
GET/v1/auth/sessionsBearerOther devices, plus the current one marked current: true.
DELETE/v1/auth/sessions/{id}BearerSign out one device. 204.

9. Review

A lead cannot decide their own submission. The bounty is added to score and earnings once, when every submission on that project for that student is approved.

MethodPathAuthNotes
POST/v1/projects/{id}/submissionsMemberBody: { branch }. Creates the pushed and AI-review steps. 201.
GET/v1/me/submissionsBearerThe caller’s submissions.
GET/v1/submissions/{id}Owner or leadSteps: pushed, ai_review with findings[{kind: pass|warn, text}], lead_decision, bounty { amount, paid_at }, plus diff_url.
GET/v1/lead/queueLeadSubmissions waiting for a decision. 403 role_required otherwise.
POST/v1/submissions/{id}/decisionLeadBody: { action: approve | send_back, comment }.

10. Become a lead

Passing the exam (3 of 4) does not change the role. An admin confirms the in-person stage with Ylyas at POST /v1/admin/lead-applications/{user_id}/in-person, and the role becomes lead.

MethodPathAuthNotes

POST/v1/me/lead-applicationStudentStart an application.
POST/v1/me/lead-application/exam/sessionStudentReturns session_id, token, questions without answer keys, and submit_path. 201.
POST/v1/me/lead-application/exam/sessions/{id}StudentBody: { token, answers }. answers is the choice index for each question.
